60 行 X 各有 4,096 个输入。一次矩阵乘 P = X @ Wiᵀ 产生 24,896 列，依次为 q_raw、k_raw、v_raw、beta、fa、ga，列宽为 8,192、8,192、8,192、64、128、128。公式里的 Wi 和 Wo 均按模型权重的逻辑形状表示。 投影切分与模型参考计算

MTE2将 X 的分片和预排权重 Wi 从全局内存搬入 L1。每个归约分片宽 128，T.Pipelined 开两级缓冲，QKV 权重读取采用 cache_hint=4。T.copy · load_global · 分块参数
MTE1 / CubeMTE1 把 L1 的两个分片送入 Cube 的 L0A/L0B。Cube 用 acc += a @ bᵀ 累加 32 个归约分片。B10 的输出分片为 64 行 × 784 列，其中 60 行有效。T.gemm · transpose_B
FIX把 L0C 的 FP32 累加结果转为 BF16，按列写回 P。整核将投影模板的输出形参 Y 绑定到 P。T.copy(acc[…], Y[…]) · 实参映射

Gate proj · fa、ga → GF、GG

GF = fa @ WFᵀ 产生逐头衰减门输入，GG = ga @ WGᵀ 产生输出门输入。两块各有 60 个有效 token，每个 token 的 8,192 列按 64 个头、每头 128 维展开。

泳道这一段在做什么TileLang 源码
MTE2从 P 尾部取 fa 或 ga 的 128 列，并读入对应权重 WF 或 WG。每块处理 32 行 × 512 个输出列。T.copy · T.Pipelined
MTE1 / Cube / FIXMTE1 准备乘法所需的操作数，Cube 执行 activation @ weightᵀ，FIX 将结果写到 GF 或 GG。中段内部的形参 WF / WG 分别接到这两块投影结果。T.gemm · T.copy · GF / GG 参数映射

四抽头因果卷积 · P、CS → conv

每个头独立处理 Q、K、V 的各个通道。window 的前 3 行取自历史，后 6 行取自此次验证的投影。

泳道这一段在做什么TileLang 源码
MTE2读入卷积权重 CW、当前头的 q_raw / k_raw / v_raw 和 beta。Accepted[0,b] 选择卷积页，Accepted[2,b] − 1 是取三行历史的起点。T.copy · window
Vector对每个通道计算 s[t] = Σⱼ₌₀³ window[t+j] · cw[j]，再计算 SiLU(s) = s · sigmoid(s)。三个结果依次存为 conv[0]、conv[1]、conv[2]。同时将 conv[1] 写入本地 kg 的前 128 维。T.SimdVF · T.simd.vmula
MTE3把 window 的第 1 至第 8 行（从 0 计数）写回所选 CS 页，作为下次卷积可用的历史窗口。T.copy(window[…], CS[…])

以下按一个头、一个请求书写。t=0…5 是 token 序号，⊙ 表示逐通道相乘，D=128。

MTE2把 GF / GG 的当前头读到 g0 / g1，并读入 A、DT、NW。其中 A 来自模型的 A_log。读 NW · T.copy → g0/g1 · 读 A、DT、beta
Vectordecay[t] = exp(lower_bound · sigmoid(exp(A) · (g0[t] + DT)))，running[t] = ∏ᵢ₌₀ᵗ decay[i]。另算 bs[t] = sigmoid(beta[t])、gate_weights[t] = NW ⊙ sigmoid(g1[t])，并把 g0[t] 填入 kg 的后 128 维。T.simd.vexp · vdiv · vmul · bs

状态页由 Accepted[1,b] 选择。每个 Cube 配对两个头，两个 Vector 子核各取自己头的结果。

ReplaySSM · 六个 token 的因果修正

令 v[t] = conv[2,t]，以 pK[t]、pQ[t] 分别简记上一段取出的两行 proj。各个 corr[t] 按 token 顺序计算。

泳道这一段在做什么TileLang 源码
Vector对 u<t，把 k[u] 乘以从 u+1 到 t 的逐通道衰减积，再分别与 k[t]、q[t] 做内积，得 ck[t,u]、cq[t,u]。对角项 cq[t,t] = q[t]·k[t]。cq 对角项 · T.simd.vmul · vcadd
Vectorcorr[t] = bs[t] · (v[t] − pK[t] − Σ(u<t) ck[t,u] · corr[u])。输出加上当前步修正，即 r[t] = pQ[t] + Σᵤ₌₀ᵗ cq[t,u] · corr[u]。T.simd.vmula · vsub · 加当前步并转 BF16

门控 RMSNorm 与 Replay 缓存写回

每个头单独归一化。rᵦ = BF16(r[t]) 保留模型在核心输出处的精度边界，再以 FP32 计算均方根。

Vectory[t] = BF16(rᵦ / √(mean(rᵦ²) + eps) ⊙ gate_weights[t])。128 个通道参加同一个头的归约。T.simd.vcadd · vsqrt · vmul
